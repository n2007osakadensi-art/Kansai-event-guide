# 外部AI向け: 提出の仕様（自動で掲載まで完結させるために）

他のAI（Arena AI 等）が関西イベントガイドへ調査結果を提出するときの仕様です。提出は自動取り込みで処理され、**画像込みで掲載まで完結**します。完結できるかどうかは、提出の形で決まります。この仕様に沿わない提出は、処理側が探し直すため時間がかかるか、保留になります。

## 提出先と単位

- 提出先は、公開シートの「外部AI入力」タブです。入口はここ1か所だけです。スペース版ガイド（本体）とスマホ対応版の両方へ別々に書く必要はありません（処理側の連鎖が両面へ反映します）
- 1行 = 1イベントで書いてください。期間開催は開始日と終了日を分けて書きます。部が分かれる公演（1部・2部など、内容や出演者が違うもの）は行を分けます

## 1イベントごとに必要な内容

- イベント名: 主催が公式に宣言した正式名称そのまま。年号・回数・副題・地域名を足さない
- 開催日（期間開催は終了日も）、時刻（開演・開始。未定なら「未定」と書く）
- 会場: 正式名称。場所（府県・エリア）
- カテゴリ（判断に迷う場合は、根拠にした内容を備考に書く）
- 料金（分かれば。ドリンク代等の内訳も一次情報にあれば書く）
- 出演者（名前のみ。時刻は書かない）
- 内容・説明（何が行われるか）
- 主催（一次情報で分かる場合）

## 根拠の書き方

- **一次情報のURLが必須**です（主催・会場・出演者の公式サイト／公式SNS、チケット販売ページ）。まとめサイト・キュレーションは根拠にしません
- どの経路で確認したかを分かるようにしてください（会場公式／主催公式／出演者公式／チケットサイト等）
- 確認できなかった項目は「未確認」と正直に書いてください。推測で埋めた提出は、検証で矛盾が出ると保留になります

## 画像について（完結の条件）

掲載は画像込みで完結するのが前提です。提出の時点で、次を添えてください。

- **公式フライヤー・公式告知の画像URLを必ず添える**こと。画像は一次情報（公式サイト・公式SNS・チケットページ）に載っているものに限ります
- 複数枚ある場合は全部を添えてください。2枚目にタイムテーブルや会場案内図が載っていることがあり、情報としての価値があります
- まとめサイトの画像、転載画像、スクリーンショットは不可です
- 公式に画像が存在しないイベントは、その旨を「画像なし（公式に存在しない）」と明記してください。その場合は画像なしで完結扱いになります。何も書かれていないと、処理側が画像を探し直し、見つからなければ保留になります

## リンクの書き分け

- チケットのURLは、その公演自体の販売ページだけを書いてください（主催のトップページや別公演のページは不可）
- 出演者個人のSNSやホームページは、イベントのリンクとして書かないでください（出演者名だけを書けば十分です）

## 提出後に起きること

1. 自動取り込みが、6時間ごとの定期処理（＋運営者の指示時は即時、夜23時のバックストップ）でタブを確認します
2. 一次情報で再検証し、問題なければスペース版ガイド（本体）へ登録します。画像は本体への保存と同時に公開URL化され、記録されます
3. シートへ同期され、スマホ対応版にも画像つきで表示されます
4. 結果はタブの処理状況・処理メモに返ります。「保留」の場合はメモに理由が書かれるので、一次情報の根拠を足して再提出してください

## してはいけないこと

- 両面への別々の提出（二重登録と不整合の元）
- タイトルへの装飾の追加（年号・回数・副題）
- 推測での穴埋め（分からない項目は「未確認」と書く）
- 中止になったイベントの削除（消さずに、中止であることと理由を書いて提出する）
