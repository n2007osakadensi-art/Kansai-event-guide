# トップ／イベントのタブ分離 仕様（2026-11-27、Kota指示）

## 指示
「どこからでもトップページに戻りやすいように。今更ながらイベントタブとトップページタブは別にあるべきでは？」

## 現状
- 「イベント」タブ（view=all）がトップページを兼ねている。特集バナー・おすすめ・ランキング・おすすめフォロー・サイネージ帯・ティッカーはすべて「view=all かつ条件なし」のときにだけ出る仕様で、一覧とトップが同一画面だった。

## 変更
- タブの先頭に「トップ」（view=home）を新設し、「イベント」（view=all）と分ける。
- トップ（home）: 今の初期画面そのもの。特集バナー（クリスマス／アフター万博）、おすすめ棚、関心ランキング、おすすめフォロー、好みCTA、サイネージ帯、トップティッカーはトップだけに出す。下にはイベント一覧が続く（従来の初期画面と同構成）。
- イベント（all）: 一覧専用。棚・バナーは出ない。検索・絞り込み・カテゴリの挙動は従来どおり。
- 初期表示はトップ。画面状態の復元（kg_ui_state_v1）は従来どおり（保存された表示があればそれを復元。「イベント」で離れた場合はトップから開く＝従来の all の扱いと同じ）。
- 「一覧に戻る」等の既存導線はイベント（一覧）へ戻すまま（文言どおり）。
- タブ行は従来どおり上部に吸着表示されるため、詳細・DB・プラン等の各画面からも「トップ」タブ1つで戻れる。タイムライン（全画面オーバーレイ）とイベント詳細モーダルは従来どおり閉じてからタブで戻る。
- フィードアプリにはタブが無く対象外。

## 実装メモ
- isHome の条件を view==="home" に変更（renderHomeExtras 内）。
- 特集バナー2種・サイネージ帯・ホームティッカーの表示条件も view==="home" へ。
- 0件時の案内は home／all の両方で出す。
- view の初期値を "home" にする。filtered() 等の一覧処理は "home" を "all" と同じ素通し扱いにする（特別な絞り込みを持たない）。
