# 回しプランを「自分で入れた分だけ」にする仕様（2026-11-25、Kota指摘）

## 問題
従来の回しプランは、お気に入り・推しが出演するイベントの時刻表から自動で組み立てていた。
そのため、本人がまだ何もプランを考えていなくても、マイページやプラン画面に
「回しプラン N件」と件数が出て、プランが出来ているように見えた。

## 変更後
- 回しプランは専用の保存（端末内 `kg_trial_plan_v1`）を持ち、**本人が入れたイベントだけ**で構成する。
- 入れる場所はイベント詳細の「＋ 回しプラン」ボタン（入れた後は「✓ 回しプラン」で取り外し可能）。
  カード上には置かない（従来ルールどおり、プランの追加・削除は詳細の中だけ）。
- 件数表示（マイページの統計・スライドバーの「プラン今日」・今日の回し）は、すべて手動プランの分だけを数える。
  何も入れていなければ 0件で、「プランはまだありません」の表示になる。
- プラン画面（回しプランビュー）:
  - 本体は手動プランの日程表。しおり・カレンダー書き出しも手動プランだけ。
  - その下に「候補（推し・お気に入りの今後の予定）」として従来の自動抽出を残し、
    「＋追加」で1件ずつプランへ移せる。候補はあくまで候補で、件数には数えない。
  - 各日の「このあと回せる候補」の「追加」も、プランへ入れる動作に統一する。
- タイムラインの「回しプラン」範囲と、回せる現場の起点（今日のプラン）も手動プランを基準にする。
- マイページのセクション（今日の回し／お気に入りの管理／リスト）は、見出しを押して開く形にし、
  初期状態では場所を取らない（推し一覧と同じ考え方）。

## 移行
- 既存のお気に入り・推しはそのまま候補として残る。自動でプランへは移さない
  （移すと「考えていないのにプランがある」状態が再現されるため）。
