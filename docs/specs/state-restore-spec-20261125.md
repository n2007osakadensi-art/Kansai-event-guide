# 画面状態の復元仕様（2026-11-25、Kota指摘「PWAで戻るたびにトップに戻されるのはシームレスではない」）

## 実測（v114時点）
検索「ライブ」・タイムライン（フィード/お気に入り範囲）・詳細モーダルを開いた状態で
再読み込みすると、検索・タイムライン・詳細・スクロール位置のすべてが消えた。

## 仕様
- 本体: 端末内に画面状態を保存する（`kg_ui_state_v1`、4秒ごと＋画面を閉じる/隠す時）。
  保存内容: 表示中のビュー、検索語、選択中カテゴリ、一覧のスクロール位置、
  タイムライン（開いていれば 表示形式・範囲・位置）、開いている詳細のイベント、
  アーティスト/会場/主催の詳細を開いていればその対象。
- 起動時、データの初回表示が済んだ時点で一度だけ復元する。7日以上前の状態は使わない。
- 共有リンク（`?event=`）が付いている場合はそちらを優先し、復元はしない。
- データがまだ無いうちは保存で上書きしない（復元前の状態で消さない）。
- フィードアプリ: 検索語と表示位置（何件目か）を保存し（`kg_feed_ui_v1`）、
  起動時の初回表示後に復元する。範囲（スコープ）は従来どおり保存済みのものを使う。

## 対象外
- フィルタパネルの開閉状態、編集中のフォーム内容は復元しない。
