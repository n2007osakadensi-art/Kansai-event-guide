# タイムラインのマイページ統合 仕様（試作サイト v106、Kota 2026-11-25 10:50 指示）

## Kotaの指示
タイムラインで推しと回しとリストを統合し、SNSの自分のプロフィールのように
見せられたら使い勝手が良くなる。他人には表示しない形で。

## 前提（既存の整理）
- 推し・お気に入り・リスト・フォローは全て端末内データ。公開・集計はしない
  （プロフィールシートにも「この端末の中だけ、他人に公開されない」と明記済み）。
- タイムラインは既にスコープ切替（リスト別／お気に入り・行きたい・気になる・
  フォロー中の固定スコープ）を持つ。不足しているのは「自分のプロフィール」
  として全体を束ねる入口と要約。

## 実装（index.html のタイムライン内のみ）
1. タイムライン上部に「マイページ」カードを置く（オーバーレイ内、スコープの上）。
   - フィード表示: 完全なプロフィールカード。
     - アバター（★の円）＋「マイページ」＋アカウント状態（ヘッダーのログイン
       ボタンの文言をそのまま使う: 管理者モード／ログイン中／ゲスト等）
     - 注意書き「あなたの端末の中だけの表示です。他人に公開されることはありません」
     - 統計ボタン5つ: 推し（組）／お気に入り／回しプラン／リスト／フォロー。
       タップで該当ビューへ（推し→推しタブ、お気に入り→お気に入りタブ、
       回しプラン→プランタブ、リスト→リストタブ、フォロー→タイムラインの
       フォロースコープに切替えて留まる）
     - 推しチップ（最大12組）: タップでその推しだけの表示（v104の個別表示）へ
     - 「今日の回し」: 当日のプランを最大4件、時刻・出番・イベント名で表示。
       タップで詳細をタイムラインの上に開く。5件以上は「全部見る」でプランへ
   - スライド表示: 1行の細いバー（マイページ／推しN組・プラン今日N件・
     リストN件／開く）。タップでフィード表示へ切替えて完全カードを出す。
1b. **お気に入りとブックマーク（リスト）もプロフィール画面で管理できる**
    （Kota 2026-11-25 10:52 追加指示。見るだけでなく、その場で管理まで）
    - 「お気に入りの管理」: 今後のお気に入りを最大8件並べ、タップで詳細、
      ✕でその場で解除できる。9件以上は「全部見る」でお気に入りタブへ。
      解除したらタイムラインと件数も即更新する。
    - 「リスト（ブックマーク）」: 自分のリストを名前＋件数で並べ、タップで
      そのリストをタイムラインに流す（スコープ切替）。名前変更・削除などの
      編集は「リストの編集」からリストタブへ。
2. フィード本体・スコープ・並び替えは従来どおり変えない。
3. 新しい常設ナビゲーションは足さない（タイムライン内部の改修に留める）。
