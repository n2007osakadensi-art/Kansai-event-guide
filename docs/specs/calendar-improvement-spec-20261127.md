# カレンダー改善 仕様（2026-11-27、Kota指示の統合版）

Kotaの指示（2026-11-27 13:47）:
- カレンダーは「日ごとに件数が分かり、日を選んでイベントを見られる」ものとして頼んだはず（現行の骨格はその通り）。
- 自分のスケジュールとの切り替えがあると良い（現行「自分の予定」があるが、確認したら中身が空っぽだった）。
- 問題点に対策しながら、より良いカレンダーにする。
- ユーザーがカレンダーに自分で記載しなくて良いようにする（予定は既存の印・フォロー・プランから自動で作る）。
- カレンダーだけを切り出したウィジェット（単独アプリ）があると最高。
- 週間・2週間の表示、週の始まり（日曜／月曜）の切り替えなど細かく設定できるように。
- 週間カレンダーはカレンダータブだけでなく、トップページの良い場所にも置けるように。その際、流れる文字（ティッカー）と競合するので、表示は「両方／流れる文字のみ／週間カレンダーのみ／両方非表示」を選べるのがベスト。

## 現行の問題点（コードで確認済み）

1. 「自分の予定」が空に見える主因:
   - 対象が お気に入り／行きたい／気になる／推し出演 の4種だけで、**回しプランのイベントと、会場・主催者フォローのイベントが入っていない**。スペース版の「予定カレンダー」はプラン中心なのに、スマホ版はプランを含まない。予定の置き場がプランの人には空になる。
   - 空の月の案内文が「印を付けてみてください」だけで、自動で入る対象（フォロー・プラン）の説明がない。
2. 全イベント側の件数は現在の検索・絞り込み条件を反映するが、カレンダー画面には条件が効いていることが注記文でしか分からず、条件のせいで空に見えることがある。解除導線がない。
3. 日リストに回しプランへの導線がなく、予定の重なり警告もない（スペース版には両方ある）。
4. 表示は月間のみ。週の始まりは日曜固定。

## 設計

### A. 自分の予定の自動化（記入不要）
- 種別を6種に拡張: お気に入り（fav）／行きたい（want）／気になる（int）／推し出演（oshi）／**プラン（plan）**／**フォロー（follow: 会場・主催者フォローのイベント）**。色丸と凡例を対応させる。
- 判定: plan = planIds（アクティブなプラン）に含まれる。follow = venueFollowed(ev.venue) または主催者フォロー一致。推しは従来どおり oshiNameHit（解決込み）。
- 空の月の案内を実態に合わせて書き換える（印・推し・フォロー・プランから自動で集まること、付け方への導線）。

### B. 全イベント側の見える化
- 検索・カテゴリ・絞り込みのいずれかが効いている時、カレンダー上部に「条件で絞り込み中」チップ＋「条件を外す」ボタンを出す。外すと検索語・カテゴリ・絞り込みを初期化して再描画する。

### C. 日リストの改善（スペース版と同等に）
- 選択日のイベントにプランが含まれれば「この日の回しプランを開く」ボタンを出す（プランタブへ移動）。
- 自分の予定モードでは、その日の予定（開始・終了時刻が分かるもの同士）で時間が重なるものに「⚠ 他の予定と時間が重なっています」を付ける。

### D. 表示モードと週の始まり
- モード切替: 月間／週間／2週間。ナビ（前へ／次へ）はモード単位で動く。タイトルは 月間=「YYYY年M月」、週間・2週間=「M月D日〜M月D日」。
- 週の始まり: 日曜／月曜を切り替え（カレンダー内の切替＋好み設定に保存、既定は日曜）。曜日ヘッダーとグリッドの並びが追随する。
- 状態は prefs に保存: calMode（month/week/2week）、weekStart（0=日曜,1=月曜）。カレンダーの選択日・表示アンカーも従来どおり端末内に保持。

### E. トップページへの週間カレンダー配置
- トップ（home）のティッカー帯の位置に、週間ストリップ（7日分: 曜日・日付・件数・自分の予定の丸印、タップでカレンダータブのその日を開く）を置けるようにする。
- 表示設定（好み＋トップ帯の近くの切替ではなく設定として保存）: topBand = both（両方）／ticker（流れる文字のみ）／week（週間カレンダーのみ）／none（両方非表示）。既定は both。
- 週間ストリップの週の始まりは D の設定に従う。件数は全イベント基準（長期開催を除く現行カレンダーと同じ数え方）、丸印は自分の予定の種別。

### F. カレンダー切り出し（/calendar/）
- フィードと同じ切り出し方で、カレンダーだけが開く単独PWA（/calendar/、専用Service Worker）。同じシートデータを読み、同じ端末データ（印・フォロー・プラン・設定）を共有する（同一オリジン）。
- 機能は A〜D と同等（月間/週間/2週間、全イベント/自分の予定、日リスト→イベント詳細は本体サイトの #/event/<id> へリンク）。編集・投稿系は持たない。

## 検証
- 自分の予定: 印なし・プランのみの状態でもプランの日が埋まること。フォロー会場のイベントが follow として出ること。
- 条件チップ: 検索語を入れた状態でカレンダーを開くとチップが出て、外すと件数が戻ること。
- モード: 週間/2週間で前後移動とタイトルが正しいこと。月曜始まりで曜日並びが変わること。
- トップ帯: 設定4値で表示が切り替わること。週間ストリップの日タップでカレンダーのその日が開くこと。
- /calendar/: 単独で開いて同じデータ・同じ自分の予定が見えること。
