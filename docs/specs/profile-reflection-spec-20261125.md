# プロフィールの反映と導線 仕様（2026-11-25 Kota指摘「タイムラインから確認する情報がデータベースの情報が反映されてない」「SNSのアカウントっぽく見せる機能が未着手な気がする」）

## 監査で分かったこと
- SNSアカウント風のプロフィール（カバー＋アイコン＋ハンドル＋統計＋フォロー＋予定/情報タブ）は、アーティストと会場についてはプロフィールシートにも詳細ページにも実装済みだった。
- ただし実際の導線では届いていなかった：
  1. **主催のプロフィールが読み込まれていない** — シートに主催タブがあるのに、サイトはアーティスト/会場/読み仮名しか読んでおらず、主催は名前と件数だけの表示になっていた。
  2. **タイムラインからの導線が外に出る** — タイムラインでイベント詳細を開き、出演者・会場・主催を押すと、タイムラインを閉じて別ページ（名簿の詳細）へ飛んでいた。アカウント風のシートはタイムラインのカードの小さなチップからしか開けなかった。
  3. **会場・主催の予定一覧に出演者が出ない** — 行には日付・タイトル・時刻・会場だけで、誰が出るのか分からなかった。

## 直すこと
1. シートの主催タブも読み込み、主催プロフィール（X等のリンク・ハンドル・紹介文があれば） をシートと詳細ページの両方に反映する。
2. タイムライン（またはプロフィールシート）から開いたイベント詳細では、出演者・会場・主催を押すと**その場でプロフィールシートを開く**（タイムラインを閉じない）。シートを閉じれば詳細に戻る。一覧側から開いた詳細では従来どおり名簿の詳細ページへ。
3. 会場・主催のプロフィールで予定一覧の各行に出演者を表示する（先頭4組＋ほか）。アーティストの行は従来どおり会場表示。
4. データベースに情報が無いものは従来どおり出ない（無い情報を作らない）。

## 変えないもの
- プロフィールのデータそのもの（シートへの書き出しは同期側の担当）。アイコン/カバー画像の公開URL化が済んでいないアーティストは、表示側は受け皿だけ用意し、画像が届けばそのまま出る。
