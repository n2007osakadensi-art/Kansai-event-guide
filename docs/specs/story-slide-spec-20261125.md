# スライドのストーリー化 仕様（2026-11-25 Kota指示「スライドの機能をInstagramのストーリーっぽく」）

対象: 試作サイトのタイムライン「スライド」表示のみ。フィード表示・本体の他の画面は変更しない。

## 現状（v127まで）
- スライドはメディア（flex:1）＋下に本文（日付・タイトル・会場・出演者・チップ・プロフィールリンク）の縦並び
- 自動送り8秒＋下部に1本のプログレスバー、前へ／次へボタンと件数
- 操作: スワイプで前後、タップで詳細を開く、押している間は自動送り停止（v90）

## ストーリー化の内容
1. **分割プログレスバー**: ステージ最上部に、現在の範囲のスライド数（終了スライドを含む）分のセグメントを並べる。済んだ分は満ち、現在の分は8秒かけて満ちるアニメーション、未達は薄く。従来の下部1本バーと前へ／次へボタン・件数表示はスライド表示では隠す（件数はストーリーヘッダーへ移す）。
2. **全面メディア**: 画像がステージ全体に広がり（cover）、本文は下部にグラデーション（透明→黒）越しの白文字で重ねる。画像なしはカテゴリ色の全面＋ラベル（従来のプレースホルダを全面化）。
3. **ストーリーヘッダー**: メディア左上に円形アイコン（カテゴリ色＋頭文字）＋会場名（なければ主催・カテゴリ）＋日時。右上に件数（3 / 60）。
4. **タップで前後**: メディア／ステージのタップは、左35%＝前へ、右65%＝次へ（現在の「タップで詳細」は廃止）。チップ・プロフィールリンク・ボタン類のタップは従来どおりその動作を優先。
5. **詳細導線**: 各スライド下部に「詳細を見る」ピルボタンを置き、タップで従来の詳細モーダルを開く。
6. **長押しで一時停止**: 押している間は自動送りとセグメントのアニメーションが止まり、離すと残り時間から再開する（従来の押下中停止を、残り時間の保持まで含めて実装）。
7. **スワイプ・自動送り・終了スライド**: 従来どおり（スワイプ前後、8秒自動送り、最後に終了スライド→先頭へ循環）。PCでは左右キーでも前後できる。
8. **動きの配慮**: prefers-reduced-motion ではセグメントのアニメーションをせず満ちた状態で示す（自動送りの挙動は従来どおり）。

## 変えないもの
- フィード表示、マイページバー、範囲バー、ティッカー、ヘッダー（2段構成）の配置
- スライドの中身の情報（日付・タイトル・会場・出演者・チップ・プロフィールリンク）
- 終了スライドの文言とボタン
