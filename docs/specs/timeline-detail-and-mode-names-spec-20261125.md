# タイムライン詳細の全画面化とモード名の変更 仕様（2026-11-25 Kota指摘）

## 1. 詳細の閉じにくさへの対応
指摘: タイムラインから開いた詳細は✕が小さく、スクロールすると流れてしまい閉じにくい。
- 対象は**タイムライン（両モード）から開いた詳細だけ**。本体の一覧から開いた詳細は従来どおり。
- **スマホ幅（700px未満）では詳細を画面いっぱい（高さ100dvh・角丸なし）で表示**する。
- 詳細の最上部に**「‹ タイムラインに戻る」バーを固定表示**し、どれだけスクロールしても常に押せる形で閉じられるようにする。閉じると元のタイムラインの位置に戻る（従来どおり）。
- PC幅では従来のモーダル表示のまま（バーは出ない）。

## 2. モード名の変更
指摘: 「スライド」「フィード」は機能的に適切でない（フィードは別アプリの名前と重なる／スライドは実態がストーリー形式）。
- スライド → **ストーリー**（1件を全画面で自動送りする表示）
- フィード → **一覧**（マイページごと縦に流して眺める表示）
- 表示名のみの変更。端末内の保存値（slide/feed）やデータ構造は変えない。
- 開始ページ設定の「フィード（タイムライン）」表記も「タイムライン」に統一する。
