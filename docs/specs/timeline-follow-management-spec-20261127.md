# タイムラインのフォロー管理と表示統一 仕様（2026-11-27、Kota指示2件）

## 指示
1. 「タイムラインの機能だけ全てフォローに統一した方が前方綺麗では？行きたい、気になる、行くのボタンはそのままで」— 裏側の機能（推し／会場フォロー／主催フォローの区別）はそのまま、タイムラインの表側の言葉だけ「フォロー」に統一する。行きたい・気になる等のイベントへの印は対象外。
2. 「アーティストを統合前に作業して2つのアーティストが残ったままなバグが発生したので、自分のSNSっぽいプロフィールからフォローを外せる機能を。と、同時にもっといい感じのデザインに」— 統合前の名前で登録した推しが残ると、その名前のページからは外しようがない。マイページ（SNS風プロフィール）から、登録されている名前そのものを直接外せるようにする。あわせてマイページのデザインを整える。

## 変更（タイムラインのマイページ）
- 統計ボタンから「推し（組）」を独立項目として外し、「フォロー」（推し＋会場＋主催の合算）に一本化する。統計は フォロー／お気に入り／回しプラン／リスト の4つ。
- 「フォロー」を押すと管理パネルが開く（従来は押すと即フォロー中表示だった。フォロー中を流す操作はパネル内の「フォロー中をタイムラインで見る」ボタンへ移す）。
- 管理パネルは アーティスト／会場／主催者 の3節:
  - アーティスト行: アイコン（あれば画像、無ければ★の丸）＋名前＋次回出演・件数。本体タップ＝そのアーティストだけをタイムラインに流す（従来の推し行と同じ）。右端の ✕ ＝登録名そのものを推しから外す（名前解決を通さないので、統合前の古い名前・別表記でも外せる）。
  - 会場／主催者行: 名前＋今後の件数。本体タップ＝プロフィールシートを開く。✕ ＝登録名そのものをフォローから外す。
  - 外したあとは件数・統計・タイムラインをその場で更新し、トーストで知らせる。
- 範囲チップから「推しが出る」を外す（フォロー中チップが内包する）。アーティスト単独表示中のチップ表記は「フォロー：名前 ✕」にする。
- スライド表示のマイページバーの文言「推し N組」→「フォロー N」。

## デザイン
- マイページ上部にグラデーションのカバーバンド＋大きめのアバター丸＋名前／状態のSNSプロフィール風ヘッダー。
- 統計は枠箱ボタンから、数字（大）＋ラベル（小）のセグメント行に変更し、選択中はアクセント色＋下線で示す。
- フォロー行は頭文字／画像の丸アイコン付きの行にし、✕ は小さな丸ボタンにする。
- 色はタイムライン既存のダーク基調＋ゴールドのアクセントを踏襲する。新規の常設UIは増やさない（マイページ内だけの変更）。

## 対象外
- 本体サイト（タイムライン外）の「推し」表記は変えない（詳細の推しボタン等は従来どおり）。
- フィードアプリにはマイページが無いため対象外。
- 裏側のデータ（favPerfs／follows の保存形式・同期）は一切変えない。
