# タイムライン内検索の機能そろえ 仕様（2026-11-25 Kota指摘「サジェストなど機能が欠落しててただの検索だけ」）

## 指摘の内容
v130で入れたタイムライン内検索は、文字の一致だけで絞る素の検索のみで、本体の検索にある補助機能が無かった。

## 本体の検索にあるもの（そろえる対象）
1. **サジェスト（入力中の候補）**: アーティスト（メンバー名でも）／会場／イベント名の候補を、読み・辞書・別名まで使って出し、種別チップ付きで並べる。
2. **0件のときの案内**: 
   - 話数・回数の指定が外れたら、そのシリーズの開催一覧を出す
   - 日付入りの検索で0件なら、日付を外した名前で合う開催を実際の日付つきで「日付違いの候補」として出す
   - 名前の候補を「こちらでは？」として出す

## タイムライン側の実装
- 候補の収集は本体と**同じ関数**を使う（本体のサジェストから候補収集だけを共通化し、両方で使う。二重管理でズレないようにする）。
- 候補の見た目はタイムラインの暗い画面に合わせた配色で、入力欄の直下に出す。
- 候補を選んだら、その候補の語をタイムラインの検索語にして検索する（タイムラインから出ない）。本体の「候補だけに完全一致」とは違い、タイムラインの検索は全イベントへの文字検索なので、その語で検索する形にそろえる。
- 0件のときの案内も本体と同じ3種を、検索注記エリアに出す。開催の行を選ぶとそのイベントの詳細を開く。「こちらでは？」の候補を選ぶと、その語で検索し直す。
- 検索の一致そのもの（入力した語のまま・候補が結果を歪めない原則）は変えない。候補と案内はあくまで補い。

## 対象外
- フィードアプリの検索の候補対応は今回の対象に含めない（別途）。
