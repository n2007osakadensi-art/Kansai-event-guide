# フィード専用アプリの検索バー 仕様（Kota 2026-11-25 13:01 指示）

## Kotaの指示
「フィードにも検索バーを。関西イベントガイドの本体に戻らなくても
SNS使ってる感覚で完結するように」
フィードアプリの中でイベントを探せるようにし、本体へ戻らなくて済む形にする。

## 実装（feed/index.html）
1. ヘッダー内（スコープバーの下）に検索バーを常設する。入力欄＋解除ボタン。
2. 検索の照合は本体と同じ土台にそろえる。
   - 正規化は本体の normSearch をそのまま移植（半角カナ→ひらがな、全角英数→
     半角、小文字化、カタカナ→ひらがな、小書き仮名の正規化、中点除去）。
   - 照合対象（hay）は、タイトル・会場・スペース注記・出演者・カテゴリ・
     エリア・府県・主催・説明・料金・日付の表記ゆれ（YYYY-MM-DD／YYYY/MM/DD／
     M月D日／M/D）。
   - 検索辞書（同梱 assets/dict.json ＋ シート「検索辞書」タブ）も本体と同じ
     形で読み、タイトル・会場・出演者の辞書語を hay に含める。出演者の読み
     （assets/readings.json）も含める。
   - クエリは1つの文字列として部分一致（本体の原則どおり、自動分割や
     自動条件付けはしない）。
3. 検索中はスコープ（範囲）に関係なく全イベントから探す。並びは開催日順。
   終了イベントは、本体の救済と同じく「終了分だけが一致したとき」に限り
   表示し、その旨を検索結果の注記に出す。
4. 結果は通常のフィードカードで流れ、件数を検索バーの下に注記する。
   0件のときは一致なしの表示と「検索を解除する」ボタンを出す。
   スコープのチップを押したら検索は解除される。
5. フィードのワーカーのキャッシュ名を上げる（kg-feed-v2）。

## 本体との差（正直な記録）
- グループのメンバー名での展開（本体はアーティストプロフィールから展開）は
  フィードでは未対応。プロフィールをフィードが読み込んでいないため。
  必要になったら次段で足す。
