# マイページのセクションをパネル化に統一 仕様（2026-11-25 Kota指摘）

指摘: 「今日の回し」「お気に入りの管理」「リスト（ブックマーク）」の行が表示しっぱなしで邪魔。

## 内容
- マイページカードから、上記3つのセクション行（見出しボタン）を**撤去**する。カードは既定で「アカウント行＋注記＋数字ボタン5つ」だけになる。
- 中身は、推し（v115）と同じ方式に統一する：対応する**数字ボタンを押した時だけ、その下にパネルとして開く**。もう一度押すと閉じる。同時に開くパネルは1つだけ。
  - 回しプラン → 今日の回しパネル（今日の予定＋「回しプランを全部見る」で範囲表示へ）
  - お気に入り → お気に入りの管理パネル（今後のお気に入り＋✕で外す＋「全部見る」で範囲表示へ）
  - リスト → リストパネル（各リストをタップで範囲表示／編集ボタンでリスト画面へ）
  - 推し → 推しパネル（従来どおり）
  - フォロー → 従来どおり「フォロー中」の範囲表示へ切り替え（パネルなし）
- 範囲表示へ移る操作（パネル内の「全部見る」、リストの行、推しの行）をするとパネルは閉じる。

## 変えないもの
- 各中身の内容・件数の定義、ストーリー表示の1行バー、範囲バーや検索の挙動。
