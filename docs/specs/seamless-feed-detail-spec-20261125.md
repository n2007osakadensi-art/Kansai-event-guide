# タイムライン／フィード内で完結する詳細とマイページ遷移 仕様（v109、Kota 2026-11-25 13:25 指示）

## Kotaの指摘
タイムラインやフィードで項目を選ぶとトップ（本体の一覧）に戻ってしまい、
シームレスではない。全部、フィード（タイムライン）の中で開けるようにする。

## 対象と実装

### フィード専用アプリ: 詳細をフィード内で開く
- カードの「詳細を見る」は、本体（../?event=）へ飛ばさず、フィード内の
  詳細シート（ボトムシート）で開く。
- 詳細シートの中身: 画像、タイトル、日時（日付＋時間帯）、会場（スペース注記）、
  料金、出演者（全員）、説明、主催、公式リンク（公式サイト／チケット／X／
  Instagram、あるものだけ）。お気に入り・行きたい・気になるの切り替えも
  シート内でできる。
- データはフィードが既に読み込んでいる lite＋details の範囲で出す。

### 試作サイトのタイムライン: マイページの遷移をタイムライン内に
- 推しチップ: 本体の推しタブへ閉じて移動するのをやめ、タイムラインの範囲を
  「その推しのイベント」に切り替えて留まる（範囲バーに推し名のチップが出て、
  押すと解除）。
- 統計ボタン: 推し→範囲「推しが出る」、お気に入り→範囲「お気に入り」、
  回しプラン→範囲「回しプラン」（プランの日時順に並べる）、リスト→自分の
  リストの範囲に切り替えて、いずれもタイムラインに留まる。
  フォローは従来どおり範囲切替で留まる。
- 「お気に入りを全部見る」「今日のプランを全部見る」も、それぞれ範囲切替で
  タイムライン内に開く。
- 範囲バーに「推しが出る」「回しプラン」のチップも追加する。
- 残る本体への移動は「リストの編集（名前変更・削除）」だけ。これは項目選択
  ではなく管理操作で、編集UIが本体のリストタブにあるため。報告時に明示する。

## 検証
- フィード: カードの詳細がシートで開くこと、リンクと出演者が出ること、
  シート内のお気に入り切替が効くこと、本体へ遷移しないこと。
- タイムライン: 推しチップ→その推しのイベントだけが流れること、統計の
  お気に入り／回しプラン→範囲が切り替わって留まること。
