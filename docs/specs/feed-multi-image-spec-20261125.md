# 複数枚画像の表示対応 仕様（2026-11-25 Kota指示・メイン経由「反映する時はスマホ対応版へちゃんと複数枚画像の対応を」）

## 現状の確認
- 本体（試作サイト）の詳細: 複数枚ギャラリー実装済み — 横スワイプ（スナップ＋ドラッグ）、ドット＋枚数カウンタ（1/N）、前後ボタン、タップで拡大表示（ライトボックス）。データはシートの events_images タブと同梱JSONの両方を読み、イベントごとに枚数の多い方を採用。画像データの到着が詳細表示後でもギャラリー付きで開き直す。
- フィードアプリの詳細: 1枚目しか表示していない（複数枚データ自体を読んでいない）← 今回の対象。

## フィードアプリへの実装
1. **データ**: 本体と同じ2経路（シート events_images タブ＋同梱 assets/event-images.json）から複数枚URLを読み、イベントごとに枚数の多い方を採用する。到着が詳細表示後なら、開いている詳細へ反映する。
2. **詳細シート**: 2枚以上ある場合は横スワイプのギャラリー（スナップ）＋枚数表示（n/N、スクロールで更新）にし、1枚の場合は従来どおり。
3. **拡大表示**: 画像タップで全画面ビューアを開く（スワイプで移動、枚数表示、✕で閉じる）。フィードから離れない。
4. カードの画像は従来どおり1枚目のみ。

## 変えないもの
- 本体のギャラリー仕様、画像の公開・シート反映の進め方（メイン側の滴下・突き合わせ）。
