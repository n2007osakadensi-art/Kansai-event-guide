# タイムライン内検索 仕様（2026-11-25 Kota指摘「タイムライン・フィードに検索機能が見当たらない」）

対象: 試作サイトのタイムライン（スライド／フィード両表示）。フィードアプリには検索バーが既にある（2026-11-25実装・確認済み）ため、不足は本体タイムライン側。

## 内容
1. **検索バーの常設**: タイムラインのヘッダー直下に検索入力欄（＋消去ボタン）を常時表示する。スライド／フィードどちらの表示でも同じ場所に出る。
2. **検索の意味**: 入力中は範囲指定（推し・お気に入り・リスト等）を外し、全イベントから本体検索と同じ照合（入力文字列そのままの照合＋辞書・読み・話数・簡易タイトル等の既存ルール）で探す。フィードアプリの検索と同じ考え方。終了分だけが当たる場合は終了分も出す（本体検索の救済と同じ）。
3. **状態表示**: 検索中は「『○○』の検索結果 N件（全イベントから検索中・範囲指定は解除）」の小さな注記を出す。結果は開催日順、最大120件。
4. **範囲に戻る操作**: 範囲バーのチップやマイページの数字ボタンで範囲を選び直すと検索は消え、その範囲の表示に戻る。消去ボタン／入力を空にしても戻る。
5. **復元の対象に追加**: 画面復元（v120）のタイムライン状態に検索語も含める。

## 変えないもの
- 本体の一覧検索の挙動（照合ロジックは contentPass の textOnly 分岐として共有し、一覧側の経路は変更しない）
- タイムラインの範囲・並び替え・スライド／フィードの各操作
