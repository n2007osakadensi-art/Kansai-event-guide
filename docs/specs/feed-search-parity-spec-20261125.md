# フィードアプリの検索を本体・タイムラインとそろえる仕様（2026-11-25、v141）

Kota指示「全く同じ検索機能をお願いします。違うと意味がないので」への残り分。タイムラインは v139 で本体の検索処理そのものを使う形に統一済み。フィードアプリは別ページのため同じ処理をそのまま呼ぶことはできないので、同じ仕様・同じ照合規則を移植してそろえる。

## そろえる内容
- 候補（サジェスト）：本体・タイムラインと同じ候補収集（アーティスト／メンバー名／会場／イベント、読み仮名・辞書・別名・住所でも当たる）。出すためにアーティスト／会場のプロフィール（同梱データ＋シートのタブ）をフィード側でも読み込む。
- 候補を選んだら、本体と同じく「その対象だけ」の結果にする（対象の意味も本体と同じ：アーティストは別名・同一プロフィール・所属メンバー経由も含む、会場は同一施設の表記ゆれを含む、タイトルは同名開催の扱いまで同じ）。
- 手入力の照合：話数・回数（vol.○／第○回／番号だけの書き方）、住所の表記ゆれ、簡易タイトル（年号・副題を落とした形）、チケットURLの貼り付け検索まで、本体と同じ規則にする。検索対象テキストにも出演者の別名とメンバー名、会場の表記ゆれ形を足す。
- 0件のときの案内：本体・タイムラインと同じ3種（シリーズの開催一覧／日付違いの候補／名前の候補）を出し、行を押せば詳細が開き、候補を押せばその対象で検索する。
- 終了分だけが当たる場合の救済は従来どおり（既に同じ考え方で実装済み）。検索状態の復元には候補選択も含める。

## 変えないもの
- フィードの表示の形（カードの流れ・範囲チップ）。検索中は範囲指定を解除して全イベントから探す（従来どおり）。
- プロフィールの読み込みは表示と検索のためだけに使い、端末の状態（推し・フォロー等）には触れない。
